# Lessons — the skill's portable memory

Collected from every project's `harness/evolution.md` by `harness.py lessons
collect`. One line per lesson. `[ ]` means not yet acted on; `[x]` means
processed, with the skill version that addressed it. Never delete a line; a
lesson that turned out wrong gets a note saying so.

Format: `- [ ] YYYY-MM-DD · <project> · <lesson>`
